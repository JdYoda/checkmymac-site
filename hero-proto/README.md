# Герой лендинга: 3D MacBook с разборкой (прототип v3)

Одобрен Юрой 2026-08-15. Вайб — igloo.inc: фотореалистичный MacBook Pro 14 M5,
при наведении разбирается на детали с бирками-вердиктами, в покое «дышит».

## Сборка

```
python3 build_v3.py            # → v3-macbook-m5.html (самодостаточный, ~16.5 MB)
```

Шаблон `v3-template.html` + ассеты `model/` → плейсхолдеры `__GLTF_JSON__`,
`__HDR_URI__`, `__SCREEN_URI__`, `__BATT_URI_0..2__`, `__BATT_SHAPES__`,
`__PART_DEFS__`. Модель вшита как JSON в `<script id="model">`, грузится через
`loader.parse()` — работает без сервера и без внешних запросов (кроме CDN
three.js 0.161.0 через importmap, jsdelivr).

Просмотр во время правок: no-cache сервер (кэш Chrome агрессивен!):
`python3 -c` ThreadingHTTPServer с Cache-Control: no-store, порт 8935;
Юре всегда говорить жёсткий рефреш Cmd+Shift+R.

## Архитектура шаблона

- **Модель**: Sketchfab M5 (`scene-embedded.gltf`, текстуры как data URI).
  Иерархия повёрнута и отмасштабирована произвольно (цепочка scale ~0.01×35) —
  НИКОГДА не задавать смещения в локальных осях узлов напрямую.
- **Детали** (`part_defs.json`): суффикс имени узла → деталь. Поиск
  `endsWith('_'+suffix) && !startsWith('Object_')` — Object_NN это служебные
  обёртки мешей, их брать нельзя (ловили «чёрную клавиатуру»).
  Ключевые узлы: 59+60 дисплей, 49 камера, 39 клавиатура (включает решётки
  динамиков!), 34/36 кружок Touch ID, 40 трекпад, 17 вентиляция, 31 нижняя
  крышка, 6/32/33/42/21 корпус.
- **Самокалибровка смещений**: вектор отделения задаётся в мировых осях,
  переводится в локаль узла, затем пробный сдвиг → замер фактического мирового
  смещения → нормировка. Это обходит скрытые масштабы иерархии.
- **Размещение своих объектов в осях мака**: временно `root.rotation.y = 0`,
  расчёты через `root.worldToLocal(мировая точка)`, потом вернуть поворот.
  Вертикальные векторы (0,y,0) инвариантны к повороту вокруг Y.
- **Габариты «гуляют» между загрузками** (5.86–6.45 по size2.y) — все позиции
  привязывать к фактическим bbox узлов (plateBB, kbBB), не к константам.

## Самодельные детали (в модели их нет)

- **Батарея**: экструзия по альфа-контурам фото реальной батареи Юры
  (battseg-*.png + battshape.json), фото на верхней грани с emissive 0.5
  (иначе чёрная в тени). Позиция от bbox нижней крышки: центр по X,
  прижата к переднему краю.
- **Динамики A2442**: пара зеркальных Г-образных модулей (голова с овальным
  вуфером сзади + нога с малым драйвером). Стоят под решётками = крайние
  полосы узла 39. Материалы с лёгким emissive и приглушённым envMapIntensity —
  чёрный пластик в тени иначе не читается.
- **Кнопка Touch ID**: корпус клавиши слеплен (RoundedBox) — настоящая кнопка
  впаяна в общий меш клавиатуры и отдельно не поднимается. Копия накрывает
  оригинал; кружок сенсора ложится заподлицо.
- **Дно ниш** (клавиатура/трекпад): серые пластины 0x67686e внутри корпуса,
  чтобы вырезы не зияли чернотой. Клавиатурная — на 52% высоты узла 39
  (ниже — перекрывают внутренние слои корпуса, выше — z-fight с клавишами).
- **Лист подсветки крышки**: скруглённый прямоугольник (rrShape, r=0.18)
  чуть меньше дисплея, за ним, additive 0x4a6fd8; светится по мере отъезда
  дисплея (`p.eff`). Кант и резинка крышки НЕ светятся — они один меш
  с панелью (Object_96), материалом не разделить, поэтому свой лист.
  Плюс холодный PointLight в зазоре (displayGlow) — отблеск на клавишах.
- **Экран**: скриншот программы (model/app-screen.png, 2940×1912) подменяет
  emissiveMap материала меша Object_107 с сохранением UV-трансформа старой
  текстуры. Обновить скрин = заменить файл и пересобрать.

## Механика

- **Раскрытие**: наведение куда угодно в пределах силуэта мака раскрывает ВСЁ.
  Зона = два невидимых статичных бокса (Г-образный силуэт: основание +
  наклонная крышка). Рейкаст ТОЛЬКО по ним — движущиеся детали на состояние
  не влияют, автоколебаний нет. Закрытие с гистерезисом 260 мс.
  События с target≠canvas игнорируются (курсор на бирке замораживает
  состояние — иначе луч мимо мака схлопывал конструкцию).
- **Слои низа** (сверху вниз): топкейс → динамики (−0.156·H) →
  батарея (−0.165·H) → крышка (−0.2·H). Не менять по отдельности —
  пересекутся.
- **Дыхание**: 4 группы (display+camera / battery+speaker+body /
  keyboard+touchid+vents / trackpad), цикл T=16с, вздох D=8.8с, старты через
  4с. D > T/2 гарантирует: минимум 2 группы всегда в движении, полностью
  собранного мака не бывает. Спикеры ОБЯЗАНЫ дышать с крышкой (иначе пробьют
  её), Touch ID с клавиатурой (иначе оригинал кнопки выглянет из-под копии).
- **Бирки-выноски**: раскладка зафиксирована в константе FIXED (подобрана
  Юрой перетаскиванием 2026-08-15) — fx/fy бирки в долях героя, t/off излом
  линии (доля вдоль отрезка + перпендикуляр, живёт при движении концов).
  Появляются по p.cur (только настоящий hover, не дыхание). VENTS без бирки.
  Якоря на деталях в локали узлов — едут вместе с деталями.
- **prefers-reduced-motion**: дыхание выключено, hover остаётся с быстрыми
  переходами.

## Известные ограничения

- Страница ~16.5 MB (модель вшита). Для продакшена стоит рассмотреть внешний
  .glb с Draco + отдельные текстуры и лоадер с прогрессом.
- Камера статична (Юра так решил), тач-режим — автоцикл раскрытия каждые 3.6с.
- Кредитная строка Sketchfab-модели — проверить лицензию перед публикацией.
